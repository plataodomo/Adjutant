# Adjutant

A Windows companion for Hearts of Iron IV. Choose a role and get a complete equipment design and division template, built from your installed game and mod files.

[Download the latest release](https://github.com/plataodomo/Adjutant/releases/latest)

## Get started

1. Download `Adjutant-Portable-<version>.zip` from Releases.
2. Extract the entire ZIP into a folder you can write to.
3. Open `Start Adjutant.cmd`. Python is included.
4. Choose your installed game or mod, planning year and role.

Requires Windows x64 and a local Steam installation of HOI4. Supported profiles: vanilla, Road to 56, Novum Vexillum with Global Conflict, and Millennium Dawn. All DLC are assumed.

## Updates

Adjutant 0.9.0 and later can check this repository for releases and download updates in the background. Open **Updates > Restart to update** when ready. Automatic checks and downloads can be disabled in Updates.

Older versions need a one-time manual download. Campaign snapshots stay in Saved Games/Adjutant/data. Game and mod file changes are detected separately while the app runs.

## Features

- Complete land, air and naval equipment builds, with matching divisions where applicable.
- Economy, Balanced and Elite priorities, with enemy and terrain choices.
- Doctrine paths, earned mastery and division slot limits.
- Follow a selected local save for campaign date, research and doctrine progress.
- Production estimates, build comparisons and game artwork from your own installation.

Design statistics are planning estimates. No template is best in every situation.

Adjutant works locally without an account. Updates use GitHub; The Dispatch loads official HOI4 news from Steam when opened. Game files and saves are not uploaded. No game or mod artwork is bundled.
